Netflix Movie Rating Analysis
Project Overview
This project analyzes Netflix movie ratings to uncover trends in genres, popularity, and audience preferences. The dataset was explored and visualized using Python, Matplotlib, and Seaborn to answer key questions about movie trends.

Objectives
Identify the most frequent genres on Netflix
Determine the highest votes types
Find the most and least popular movies along with their genres
Analyze which year had the most filmed movies
Methodology

Data Preprocessing
Converted date columns to datetime format
Split the genre column to analyze each genre individually
Categorized vote averages into bins: No Popularity, Below Average, Average, and Popular

Exploratory Data Analysis (EDA)
Used statistical methods and visualizations to analyze movie trends
Identified patterns in genre frequency, voting trends, and popularity rankings

Data Visualization
Used Matplotlib and Seaborn to create bar charts and histograms for better insights

Key Insights
Certain genres dominate Netflix's content library based on frequency
Some genres consistently receive higher audience votes
The most and least popular movies were identified along with their genres
A specific year had the highest number of movie releases

Conclusion
This project provides valuable insights into Netflix's movie landscape through data preprocessing, visualization, and analysis. The findings highlight important trends that could help in understanding audience preferences.
